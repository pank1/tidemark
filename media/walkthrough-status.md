## What the status bar shows

```
⚡ you   75%  wk 28%  🕐 2h41m
│      │    │        └── time until the next window resets
│      │    └── how much of this week is left
│      └── how much of the 5-hour window is left
└── the account Claude Code is signed in to
```

The figures come from Anthropic, for the account you are already signed in to.
Nothing had to be configured for this to work.

Hover the item for both windows in full, the limits that apply to specific
models, and what has been using your week. Click it to switch accounts.

When Anthropic cannot be reached, the last figures stay on screen with a clock
icon rather than vanishing, and a `~` means the number is a local estimate
rather than a measurement.
